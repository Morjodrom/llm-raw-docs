# Local documentation search

For questions, lookups, or quotations from local documentation exports in this
project, **load and follow `LLM-docs/skills/local-docs-search/SKILL.md`**. Use its
Bash workflow for normalization, index updates, search, and section retrieval;
do not replace document search with recursive raw-file scans or remote search.
This requirement applies to local document research, not source-code navigation.
The discoverable project skill link is `.agents/skills/local-docs-search`.
